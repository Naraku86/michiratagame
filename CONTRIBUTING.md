# Contribuir

Prueba la demo y cuenta qué falla o qué deja de ser divertido. Para reportar un error incluye pasos, navegador, dispositivo y el resultado esperado; no adjuntes cookies ni bases de jugadores.

Para cambios de código:

1. Crea una rama con un cambio concreto.
2. Conserva los guardados existentes, la accesibilidad y los controles de sonido y movimiento.
3. Si cambia la economía, incluye una prueba que compruebe el comportamiento.
4. Ejecuta `npm test` y `npm run build`.
5. Describe en el pull request qué cambia y cómo lo verificaste.

No subas `data/`, `.env`, credenciales ni registros de terminal. Para nuevas imágenes, aporta recursos que puedas compartir bajo la licencia del proyecto y explica su procedencia.

Las contribuciones al proyecto se distribuyen bajo la licencia MIT de este repositorio.
